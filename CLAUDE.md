# Правила проекта «ЛАД»

Проект «ЛАД — Дом в ладу» — учебный прототип маркетплейса дизайнерского декора с оформлением заказов и доставкой.

Продукт описан в PRODUCT.md.

Стек: Next.js 16 App Router, React 19, TypeScript 5, Tailwind 4, shadcn/ui-style Button на Radix Slot.

Точные версии фиксирует package-lock.json.

Команды: `npm run dev`; `npm run typecheck`; `npm test`; `npm run test:e2e`; `npm run build`.

До выполнения покажи файлы, команды и проверки; дождись утверждения плана. Спецификацию и план сохранить в docs/specs, решение — в DECISIONS.md в том же коммите, что фича.

Коммиты делает человек: feat/fix/refactor/docs, в теле «Зачем».

Без одобрения не устанавливать пакеты, не применять миграции, не удалять данные, не менять политики доступа. Схема меняется только миграцией.

Не читать и не выводить реальные .env*, пароли, ключи и пользовательские токены. .env.example с пустыми значениями разрешён.

**Запрет проекта «ЛАД»:** Не отображать адреса доставки, номера телефонов и персональные данные покупателей в публичном каталоге и карточках товаров.

Самостоятельно коммиты не создавать.
