# Главная с каталогом «ЛАД»

Что: главная страница `/` с каталогом из восьми предметов дизайнерского декора на демонстрационных данных.

Для кого: покупатель, который выбирает декор для интерьера.

Сценарий: открыть главную страницу → перейти к каталогу или ввести запрос в шапке → просмотреть товары.

Дано: пользователь открывает `/` без авторизации, базы и ключей.
Когда: страница загружается.
Тогда: видны восемь карточек с названием, изображением с `alt`, категорией и ценой. На широком экране карточки расположены в два ряда по четыре.

Шапка от 1024 px показывает в одной строке оригинальный логотип, ссылку «Каталог», широкое поле поиска и отключённые кнопки «Войти», «Заказы», «Избранное», «Корзина». Ссылка ведёт к `#catalog`. На планшете и телефоне элементы занимают несколько строк без горизонтальной прокрутки. Фон шапки совпадает с зелёным в PNG. Пропорции и цвета логотипа сохранены.

Поиск при вводе фильтрует товары по подстроке в названии или категории, игнорируя регистр и крайние пробелы. Пустой запрос показывает восемь товаров, а запрос без совпадений показывает сообщение «Ничего не найдено».

Чего не делать: не подключать базу данных, не создавать корзину и оформление заказа на этом этапе, не устанавливать новые пакеты, не менять managed-блок `AGENTS.md`, не создавать или перерисовывать логотип.
